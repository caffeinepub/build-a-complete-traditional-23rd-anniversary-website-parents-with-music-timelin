# Specification

## Summary
**Goal:** Display the submitted comments list directly under the comment submission form within the Comments section.

**Planned changes:**
- Update the Comments section layout so the comments list (or its loading/empty states) renders immediately beneath the submission form in the same visual flow.
- Preserve the existing submit behavior: inputs clear on submit and the new comment appears after the posts query refreshes.

**User-visible outcome:** After submitting (or viewing) comments, users see the comment list, loading indicator, or empty-state message directly under the comment box without a large separating gap.
